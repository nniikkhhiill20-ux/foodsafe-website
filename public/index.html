The ethos

Zero tolerance.
Zero excuses.

India already knows what fearless enforcement looks like. Officers like Tukaram Mundhe built a public reputation for one thing: rules applied to everyone, no favours, no fear. Kitchens should be held to that same bar — and diners should be able to see it.

  • 01If a kitchen is clean, the community says so — in public. If it isn't, that's public too.
  • 02The record belongs to diners, and it travels with the restaurant everywhere.
  • 03No pay-to-pass. No quiet edits. The people's record is the record.
This is an independent citizens' initiative. It is not affiliated with, endorsed by, or connected to Tukaram Mundhe, any government official, the FSSAI, or any delivery platform. His name is referenced only as a widely-recognised example of strict public-service enforcement.
